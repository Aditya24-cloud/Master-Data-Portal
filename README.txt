Engineering Industry Tech Expo - Excel Connected Portal

Run:
1. Install Python 3.10+.
2. pip install flask pandas openpyxl
3. python app.py
4. Open http://127.0.0.1:5000

Backend:
data.xlsx is the current Engineering Industry Tech Expo master file.
Sector is treated as Category.
Replace data.xlsx later with the updated master file using the same structure.
